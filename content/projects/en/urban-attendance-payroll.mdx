# Urban Attendance & Payroll System

> Thesis (final year) project at **Politeknik LP3I Jakarta**, using **PT Urban Jakarta Propertindo Tbk** as the case study.

---

## 💡 Overview

Designed and developed a two-part system to streamline employee attendance and payroll management:

- **Mobile Attendance App** — built with **React Native**, enabling employees to clock in/out with GPS-based location tracking.
- **Web-Based Admin System** — for managers, HR, finance, and executives.

---

## ✨ Key Features

**Mobile App**

- Clock in/out with **GPS-based location tracking**.

**Web Admin System**

- Managers define **attendance zones** and monitor employee check-ins.
- Employees submit **overtime requests** for approval by their manager.
- Managers and HR **approve overtime** submissions.
- HR and finance staff process **payroll**.
- Executives review and **approve payroll documents**.
- Employees securely access and **download their payslips**.

---

## 🔗 RESTful API

Built the API with **CodeIgniter** to connect the mobile and web apps, enabling secure and efficient data flow between systems.

---

## 🧩 Tech Stack

- **React Native** | Mobile attendance app
- **PHP & CodeIgniter** | Web admin & RESTful API
- **MS SQL Server** | Data storage
- **JavaScript** | Client-side logic

---

## 🧭 Impact

Improved data accuracy, streamlined HR workflows, and reduced manual effort in payroll processing.
