# Project Background

This project aimed to automate and simplify the workflow for pension and promotion applications within the internal environment.

## Main Challenges

- Integrating distributed employee data.
- Building a tiered approval workflow based on employee rank and position.

## Technical Solution

We utilized **Laravel** for the backend API and **React** for the interface. Its key advantage lies in authorization security and database query speed.
