# Property & HR Web Development

> Full-stack web development for enterprise property management systems, serving multiple real-estate clients across Indonesia.

---

## 💡 Overview

As a Software Programmer at PT IFCA Property 365 Indonesia, I developed and maintained web-based property management systems tailored to each client's needs. The role covered the full stack — from the CodeIgniter 3 frontend and backend, RESTful APIs, and database design (MS SQL Server), to occasionally managing the client's server environment.

---

## 🏢 Clients

- Alfaland
- Urban Jakarta
- Triyasa Propertindo
- Waskita Realty (Vasaka)
- Pakuwon Group
- Vasanta Group

---

## ✨ Key Contributions

- **Payment Gateway Integration** — developed REST APIs to integrate **Sprint Payment Gateway** (payment via ATM and virtual account, incl. installments) for Vasanta Group, and **Midtrans** (virtual account transfer) for one of the property clients.
- **HR Modules** — built and maintained HR features such as **payroll**, **leave**, **payslips**, and **overtime** using PHP and MS SQL Server.
- **Property Management Apps** — customized web applications to fit each client's specific requirements.
- **Full-stack Responsibilities** — handled the CodeIgniter 3 frontend (on top of templates), backend logic, and database schema and optimization.
- **Server Support** — assisted with client server setup and maintenance when needed.

---

## 🧩 Tech Stack

- **PHP & CodeIgniter 3** | Backend & frontend (MVC)
- **MS SQL Server** | Data storage & management
- **RESTful API** | Integration with payment gateways & internal services
- **Midtrans / Sprint Payment Gateway** | Payment processing

---

## 🧭 Impact

Delivered and maintained reliable property systems used by multiple real-estate clients, including secure payment processing and HR automation that reduced manual work and improved data accuracy.
