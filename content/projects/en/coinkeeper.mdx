# CoinKeeper

> A modern personal finance management app that helps users take control of their money. Built with a focus on security, simplicity, and seamless user experience.

---

## 💡 Overview

CoinKeeper is a web-based personal finance manager that allows users to record, categorize, and visualize their financial activities — from daily expenses to long-term savings. The app is designed to help users understand their spending habits and achieve better financial control.

---

## ✨ Key Features

- **Smart Dashboard** — View income, expenses, and balance in one place.
- **Offline Support** — Uses IndexedDB for local storage and data sync.
- **Transaction Categorization** — Organize spending with custom tags and categories.
- **Encryption Layer** — Local encryption for sensitive financial data.
- **Dark/Light Mode** — Theme adjusts automatically to system preference.
- **Drag & Drop Dashboard Cards** — Customize card order using an intuitive UI.

---

## 🧩 Tech Stack

- **Next.js 15 (App Router)** | Core web framework
- **TypeScript** | Type safety and scalability
- **Tailwind CSS** | UI styling and responsive layout
- **Framer Motion** | Smooth animations and transitions
- **IndexedDB** | Offline-first local data storage

---

## 🧠 Architecture & Features

The app follows a modular architecture with feature-based components:

- `src/app/dashboard/` — Main dashboard with analytics cards.
- `src/context/WalletContext.tsx` — Global context for wallet state.
- `src/lib/encryption.ts` — AES-based data encryption/decryption logic.
- `src/lib/indexedDB.ts` — Handles data storage, versioning, and schema.
