# rendzzx.com — Personal Portfolio Website

> The website you're looking at right now — my personal portfolio.

## 💡 Overview

A personal portfolio website built with **Next.js (App Router)** and **TypeScript**, featuring bilingual support (Indonesian & English), server-rendered project pages powered by MDX, and smooth animations with Framer Motion.

## ✨ Key Features

- **Bilingual (ID/EN)** — full internationalization with a language switcher.
- **Markdown-driven projects** — projects written in MDX and rendered server-side.
- **Featured carousel** — highlights selected projects.
- **Dark theme** — modern dark UI with particle background and micro-interactions.
- **SEO-ready** — metadata, Open Graph, sitemap, robots.txt, and JSON-LD.

## 🧩 Tech Stack

- **Next.js (App Router)** | Framework
- **TypeScript** | Type safety
- **Tailwind CSS** | Styling
- **Framer Motion** | Animations
