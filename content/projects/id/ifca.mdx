# Aplikasi Web Properti & HR

> Pengembangan web full-stack untuk sistem manajemen properti enterprise, melayani beberapa klien properti di seluruh Indonesia.

---

## 💡 Gambaran Umum

Sebagai Programmer Perangkat Lunak di PT IFCA Property 365 Indonesia, saya mengembangkan dan memelihara sistem manajemen properti berbasis web yang disesuaikan dengan kebutuhan masing-masing klien. Peran ini mencakup full-stack — mulai dari frontend dan backend CodeIgniter 3, RESTful API, desain database (MS SQL Server), hingga sesekali mengelola server klien.

---

## 🏢 Klien

- Alfaland
- Urban Jakarta
- Triyasa Propertindo
- Waskita Realty (Vasaka)
- Pakuwon Group
- Vasanta Group

---

## ✨ Kontribusi Utama

- **Integrasi Payment Gateway** — mengembangkan REST API untuk mengintegrasikan **Sprint Payment Gateway** (pembayaran via ATM dan virtual account, termasuk cicilan) untuk Vasanta Group, dan **Midtrans** (transfer virtual account) untuk salah satu klien properti.
- **Modul HR** — membangun dan memelihara fitur HR seperti **payroll**, **cuti**, **slip gaji**, dan **lembur** menggunakan PHP dan MS SQL Server.
- **Aplikasi Manajemen Properti** — menyesuaikan aplikasi web dengan kebutuhan spesifik masing-masing klien.
- **Tanggung Jawab Full-stack** — menangani frontend CodeIgniter 3 (di atas template), logika backend, serta skema dan optimasi database.
- **Dukungan Server** — membantu setup dan pemeliharaan server klien bila diperlukan.

---

## 🧩 Teknologi yang Digunakan

- **PHP & CodeIgniter 3** | Backend & frontend (MVC)
- **MS SQL Server** | Penyimpanan & pengelolaan data
- **RESTful API** | Integrasi dengan payment gateway & layanan internal
- **Midtrans / Sprint Payment Gateway** | Pemrosesan pembayaran

---

## 🧭 Dampak

Menghadirkan dan memelihara sistem properti yang andal bagi beberapa klien properti, termasuk pemrosesan pembayaran yang aman dan otomatisasi HR yang mengurangi pekerjaan manual serta meningkatkan akurasi data.
