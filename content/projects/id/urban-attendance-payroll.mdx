# Sistem Absensi & Payroll Urban

> Proyek tugas akhir di **Politeknik LP3I Jakarta**, menggunakan **PT Urban Jakarta Propertindo Tbk** sebagai studi kasus.

---

## 💡 Gambaran Umum

Merancang dan mengembangkan sistem dua bagian untuk menyederhanakan pengelolaan absensi dan payroll karyawan:

- **Aplikasi Absensi Mobile** — dibangun dengan **React Native**, memungkinkan karyawan clock in/out dengan pelacakan lokasi berbasis GPS.
- **Sistem Admin Berbasis Web** — untuk manajer, HR, keuangan, dan eksekutif.

---

## ✨ Fitur Utama

**Aplikasi Mobile**

- Clock in/out dengan **pelacakan lokasi berbasis GPS**.

**Sistem Admin Web**

- Manajer menentukan **zona absensi** dan memantau check-in karyawan.
- Karyawan mengajukan **permintaan lembur** untuk disetujui oleh atasan.
- Manajer dan HR **menyetujui lembur**.
- Staf HR dan keuangan memproses **payroll**.
- Eksekutif meninjau dan **menyetujui dokumen payroll**.
- Karyawan mengakses dan **mengunduh slip gaji** dengan aman.

---

## 🔗 RESTful API

Membangun API dengan **CodeIgniter** untuk menghubungkan aplikasi mobile dan web, memungkinkan aliran data yang aman dan efisien antar sistem.

---

## 🧩 Teknologi yang Digunakan

- **React Native** | Aplikasi absensi mobile
- **PHP & CodeIgniter** | Admin web & RESTful API
- **MS SQL Server** | Penyimpanan data
- **JavaScript** | Logika sisi klien

---

## 🧭 Dampak

Meningkatkan akurasi data, menyederhanakan alur kerja HR, dan mengurangi pekerjaan manual dalam pemrosesan payroll.
